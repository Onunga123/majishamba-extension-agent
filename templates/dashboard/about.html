About Kachieng AI Agent

What the system does

Kachieng AI Agent is a climate-smart advisory system built for the Nyatike Sub-County Agricultural Office in Migori County, Kenya. It serves smallholder farmer clusters in Kachieng Ward. The system combines an MCP-based agentic pipeline, custom MCP server, LangGraph orchestration, an open-weights model run, and a strict human approval gate — so every advisory is sourced, auditable, and approved by an extension officer before any follow-up action.

When an officer requests an advisory for a cluster, the agent gathers plot history, crop calendar, weather, pest and market signals via read-only MCP tools, then drafts a sourced recommendation. The draft is reviewed and either approved, rejected, deferred, or marked as needing more evidence. Only after approval does the system create a follow-up task — nothing is sent to farmers automatically.

Roles and permissions

  • Extension Officer — request advisories, review drafts, manage field tasks.
  • Supervisor — review and approve advisories, verify field findings.
  • Viewer — read-only access to dashboards, advisories, tasks, and audit.
